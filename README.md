# siouxfalls-roofing

Rank and rent local service site for Sioux Falls Roofing. Astro, Tailwind, deployed on Vercel.

- Phone number: one constant, `PHONE` in `src/config/phone.ts`.
- Business details: `src/config/site.ts`.
- Lead form: FormSubmit, posting to `service@siouxfalls-roofing.com`.
- Services: `src/content/service-pages.ts`. Towns: `src/content/town-pages.ts` and `src/content/town-roofing.ts`.

Commands: `npm run dev`, `npm run build`, `npm test`.
